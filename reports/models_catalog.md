**Qwen3-VL 4B/8B.** Официальные model cards: [4B](https://huggingface.co/Qwen/Qwen3-VL-4B-Instruct/blob/ebb281ec70b05090aa6165b016eac8ec08e71b17/README.md), [8B](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct/blob/0c351dd01ed87e9c1b53cbc748cba10e6187ff3b/README.md); в них Instruct и Thinking названы отдельными вариантами. Разрешения взяты из закреплённых processor configs [4B](https://huggingface.co/mlx-community/Qwen3-VL-4B-Instruct-4bit/blob/2fd8dacbdb8f1e54b8c005f081ec5bf79c56376b/preprocessor_config.json)/[8B](https://huggingface.co/mlx-community/Qwen3-VL-8B-Instruct-4bit/blob/defcdea7cc7a4b0858fea563cbbce171d328e457/preprocessor_config.json); фиксированной рекомендации для A4 не найдено. Тип `qwen3_vl` проверен в обоих MLX configs; путь реализации указан в таблице, выбор класса выполняет [mlx_vlm/utils.py](https://github.com/Neywa-Labs/mlx-vlm/blob/8c061ef516e7f8b584c0d5b64f26b50d5806303b/mlx_vlm/utils.py#L198).

**Qwen3.5 4B/9B.** Официальные источники: [4B](https://huggingface.co/Qwen/Qwen3.5-4B/blob/851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a/README.md), [9B](https://huggingface.co/Qwen/Qwen3.5-9B/blob/c202236235762e1c871ad0ccb60c8ee5ba337b9a/README.md), разделы Instruct/non-thinking; веса под Apache-2.0, не только код конверсии. Закреплённые templates [4B](https://huggingface.co/mlx-community/Qwen3.5-4B-4bit/blob/0e7ffd5c629ef7719d4cbc04069232580bfa9d9c/chat_template.jinja)/[9B](https://huggingface.co/mlx-community/Qwen3.5-9B-4bit/blob/8b2b98c00a6b4d291155e4890773ca8f769aee53/chat_template.jinja) действительно обрабатывают `enable_thinking=False`; defaults изображений — [4B](https://huggingface.co/mlx-community/Qwen3.5-4B-4bit/blob/0e7ffd5c629ef7719d4cbc04069232580bfa9d9c/processor_config.json)/[9B](https://huggingface.co/mlx-community/Qwen3.5-9B-4bit/blob/8b2b98c00a6b4d291155e4890773ca8f769aee53/processor_config.json). В mlx-vlm 0.7.10 `qwen3_5` наследует multimodal Qwen3-VL и реализует ввод картинки, а не только текстовую часть.

**Gemma 4 E4B.** [Официальная карточка](https://huggingface.co/google/gemma-4-E4B-it/blob/4ecc2ba63bcac23ba4a767fc87025b1450f84c9c/README.md) указывает ≈4,5B effective / ≈8B с embeddings; веса лицензированы Apache-2.0, официальный текст — [Apache License 2.0](https://ai.google.dev/gemma/apache_2). В [карточке MLX-конверсии](https://huggingface.co/mlx-community/gemma-4-e4b-it-4bit/blob/475b9088d29754a3379866cf5aeb6b41acd313c2/README.md) стоит `license: gemma`: это противоречие метаданных, поэтому основание для лицензии в таблице — upstream. [Processor](https://huggingface.co/mlx-community/gemma-4-e4b-it-4bit/blob/475b9088d29754a3379866cf5aeb6b41acd313c2/processor_config.json) задаёт 280 visual tokens; [template](https://huggingface.co/mlx-community/gemma-4-e4b-it-4bit/blob/475b9088d29754a3379866cf5aeb6b41acd313c2/chat_template.jinja) управляет thinking; бюджеты 70/140/280/560/1120 поддерживает также [mlx_vlm/models/gemma4/processing_gemma4.py](https://github.com/Neywa-Labs/mlx-vlm/blob/8c061ef516e7f8b584c0d5b64f26b50d5806303b/mlx_vlm/models/gemma4/processing_gemma4.py#L32); автор рекомендует большие бюджеты для мелкого текста, а не принудительное 224×224 из поля `size`.

**Gemma 4 12B.** Это именно [12B Unified IT](https://huggingface.co/google/gemma-4-12B-it/blob/43c9d014b231474fa7212dbb48a762566c2b255d/README.md) с `model_type=gemma4_unified`, а не Gemma 3 12B; Apache-2.0 подтверждена официальной карточкой. Раздел Variable Image Resolution официальной карточки рекомендует большие бюджеты для OCR; точного рекомендуемого размера A4 не найдено.

**MiniCPM-V 4.5 8B.** Тип `minicpmv`, slicing и переключатель thinking подтверждены [официальной карточкой](https://huggingface.co/openbmb/MiniCPM-V-4_5/blob/14a2004908140699317e2109e90573c1e6323c36/README.md), [config](https://huggingface.co/openbmb/MiniCPM-V-4_5/blob/14a2004908140699317e2109e90573c1e6323c36/config.json) и [processor](https://huggingface.co/openbmb/MiniCPM-V-4_5/blob/14a2004908140699317e2109e90573c1e6323c36/preprocessor_config.json). [API найденного «4bit» репозитория](https://huggingface.co/api/models/ekryski/MiniCPM-V-4_5-4bit/revision/67c26b3aa5a6a03cc642d1c2d903a32ebfba9d4e?blobs=true) показывает единственный `.gitattributes`; это не готовые веса. В [mlx_vlm/utils.py](https://github.com/Neywa-Labs/mlx-vlm/blob/8c061ef516e7f8b584c0d5b64f26b50d5806303b/mlx_vlm/utils.py#L42) нет alias `minicpmv`, в [дереве 0.7.10](https://api.github.com/repos/Neywa-Labs/mlx-vlm/git/trees/8c061ef516e7f8b584c0d5b64f26b50d5806303b?recursive=1) нет модуля этого типа; проверка [0.7.12](https://api.github.com/repos/Neywa-Labs/mlx-vlm/git/trees/7230940302cbe602054650f18a2f77db945bc57a?recursive=1) и его [utils.py](https://github.com/Neywa-Labs/mlx-vlm/blob/7230940302cbe602054650f18a2f77db945bc57a/mlx_vlm/utils.py) также не нашла поддержку этого типа. Минимальная поддерживающая версия не найдена; V 4.6/o 4.5 не заменяют кандидата из плана.

**InternVL3.5 8B.** [Поиск HF по точному имени с filter=mlx](https://huggingface.co/api/models?search=InternVL3_5-8B&filter=mlx&limit=100) вернул `[]`; дополнительно просмотрены варианты имени с точкой и общий MLX-список InternVL3: готового 3.5 8B не найдено. [Официальная карточка](https://huggingface.co/OpenGVLab/InternVL3_5-8B/blob/9bb6a56ad9cc69db95e2d4eeb15a52bbcac4ef79/README.md) подтверждает Apache-2.0, картинки, tiles и thinking через R1 system prompt; [upstream config](https://huggingface.co/OpenGVLab/InternVL3_5-8B/blob/9bb6a56ad9cc69db95e2d4eeb15a52bbcac4ef79/config.json) содержит `internvl_chat` + Qwen3. **GLM-4.1V 9B.** Выбран [GLM-4.1V-9B-Thinking](https://huggingface.co/zai-org/GLM-4.1V-9B-Thinking/blob/3c1471e51dc811b589d4d12b1c1c7c1c941267c2/README.md), MIT указана в header официальной карточки; максимум 4K — заявленная возможность, не рекомендация фиксировать A4 в 4K. **lift 9B.** [Карточка oQ4](https://huggingface.co/mlx-community/lift-oQ4/blob/491aabd0050652b6a363295dd57cedb9303a693c/README.md) описывает смешанное квантование ≈4,6 bpw; [config](https://huggingface.co/mlx-community/lift-oQ4/blob/491aabd0050652b6a363295dd57cedb9303a693c/config.json) содержит общий `bits=4` и overrides до 5 бит: это нельзя помечать равномерным 4-bit в сравнении квантов. [Лицензия весов](https://huggingface.co/datalab-to/lift/blob/221e0fcecfb3f557ca123e5a6e3452d459c25d90/LICENSE) — **AI PUBS OPEN RAIL-M LICENSE (MODIFIED)**: Attachment A 2a–b ограничивает организации с revenue/funding >$5M с исключением personal/research; 2c запрещает использование конкурентами продуктов/сервисов лицензиара и не содержит такого исключения; §§7–8 требуют attribution и Share-a-Like, включая Output. Это лицензия с ограничениями коммерческого использования, не обычная Apache-2.0 и не строго «только NC»; [processor](https://huggingface.co/mlx-community/lift-oQ4/blob/491aabd0050652b6a363295dd57cedb9303a693c/preprocessor_config.json)/[template](https://huggingface.co/mlx-community/lift-oQ4/blob/491aabd0050652b6a363295dd57cedb9303a693c/chat_template.jinja) не дают отдельной рекомендации A4 или переключателя thinking, а раздел Notes карточки описывает исправление EOS на `[248044, 248046]`.

**NuExtract3 4B.** Выбрана официальная конверсия NuMind, а не только community bf16; [карточка 4bits](https://huggingface.co/numind/NuExtract3-mlx-4bits/blob/29c38269f94054282bf9ea97a20dfc6bb8bbefea/README.md) и [config](https://huggingface.co/numind/NuExtract3-mlx-4bits/blob/29c38269f94054282bf9ea97a20dfc6bb8bbefea/config.json) подтверждают affine 4-bit/group_size=64, лицензия весов — [Apache-2.0](https://huggingface.co/numind/NuExtract3/blob/c99dc8f5641b866aa0192b6ea78f84bf9f3535f1/LICENSE). [Рекомендация автора](https://huggingface.co/numind/NuExtract3/blob/c99dc8f5641b866aa0192b6ea78f84bf9f3535f1/README.md) — начинать без reasoning; в [template](https://huggingface.co/numind/NuExtract3-mlx-4bits/blob/29c38269f94054282bf9ea97a20dfc6bb8bbefea/chat_template.jinja) default mode=`content`, а наличие `template` переводит в `structured`: требуется шаблон с типами листьев, не непосредственная подстановка JSON Schema. [Processor](https://huggingface.co/numind/NuExtract3-mlx-4bits/blob/29c38269f94054282bf9ea97a20dfc6bb8bbefea/processor_config.json) задаёт диапазон pixels; рекомендуемое разрешение именно A4 не найдено; перед прогоном нужен адаптер промпта к этому контракту, иначе режим извлечения не обеспечен.

Числа можно перепроверить без скачивания весов (подставить repo/SHA из строки):

```bash
curl -fsSL 'https://huggingface.co/api/models/REPO/revision/SHA?blobs=true' |
python3 -c 'import json,sys; d=json.load(sys.stdin); s=[x for x in d["siblings"] if x["rfilename"].endswith(".safetensors")]; print("sha:",d["sha"]); print(*[(x["rfilename"],x["size"]) for x in s],sep="\n"); n=sum(x["size"] for x in s); print("sum_bytes:",n,"GB:",n/1e9,"GiB:",n/2**30)'
```

**Рекомендую первым кругом (все в 4 бит; порядок предварительный, без замеров качества)**

1. **Qwen3-VL 4B Instruct** — уже работающая исходная точка, минимальный организационный риск и большой расчётный запас памяти.
2. **Qwen3-VL 8B Instruct** — сравнение размера внутри того же семейства при оценке ≈7,761 GB вместе с добавкой 2 GB.
3. **Qwen3.5 4B** — современная альтернативная архитектура при практически таком же размере весов, как у исходной 4B.
4. **Qwen3.5 9B** — контроль влияния размера внутри Qwen3.5 при оценке ≈7,950 GB.
5. **Gemma 4 E4B IT** — другое семейство и визуальный тракт при умеренном размере весов; учитывать расхождение лицензии в карточке конверсии.
6. **NuExtract3 4B** — специализированный экстрактор на той же базе Qwen3.5 4B для сравнения со VLM после подключения его typed template.
